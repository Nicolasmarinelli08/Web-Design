# 🎓 Web Design Course Repository

Welcome to my official repository for the **Web Design** course. This space is dedicated to storing all academic projects, practical exercises, laboratory assignments, and UI/UX concepts developed throughout the semester.

The main goal of this course is to learn the core fundamentals of user experience (UX), user interface (UI) design, and modern frontend development standards.

---

## 📚 Course Syllabus & Topics Covered

*   **UI/UX Foundations:** User research, wireframing, prototyping, and usability testing.
*   **Visual Design Principles:** Color theory, typography scales, grid systems, and hierarchy.
*   **Responsive Web Design:** Mobile-first design, media queries, Flexbox, and CSS Grid.
*   **Modern Frontend:** Semantic HTML5, CSS3, and basic DOM manipulation with JavaScript.
*   **Web Standards:** Accessibility (WCAG), SEO basics, and web performance optimization.

## 🚀 How to Run the Projects Locally

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the specific exercise or project folder:
   ```bash
   cd web-design-course/03-projects/final-project
   ```
3. Open the `index.html` file in your browser, or use the **Live Server** extension in VS Code for a real-time preview.
